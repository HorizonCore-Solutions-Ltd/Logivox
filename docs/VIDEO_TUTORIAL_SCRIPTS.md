## Production Notes

### Video Recording Guidelines

**Equipment Needed:**
- Screen recording software (Camtasia, OBS, or ScreenFlow)
- High-quality microphone (Blue Yeti or similar)
- Video editing software
- Quiet recording environment

**Screen Resolution:**
- Record at 1920x1080 (Full HD)
- Use browser at 1280x720 for better readability
- Ensure UI elements are clearly visible

**Narration Guidelines:**
- Speak clearly and at moderate pace
- Pause between sections
- Emphasize key actions
- Use friendly, professional tone

**Post-Production:**
- Add intro/outro animations
- Include background music (soft, non-distracting)
- Add captions/subtitles
- Include chapter markers
- Export at 1080p, H.264 codec

**Publishing:**
- Upload to YouTube (unlisted or public)
- Embed on LogiVox website
- Create video playlists by topic
- Add video descriptions with timestamps
- Enable comments for questions

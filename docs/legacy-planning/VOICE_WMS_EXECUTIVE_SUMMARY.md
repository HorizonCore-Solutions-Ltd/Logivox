### Voice-First User Experience Examples

**Receiving workflow**:
```
Operator: "Start receiving P O 12345"
System: "Starting receiving for P O 12345. 15 lines expected."

Operator: "Scan 7890123456789"
System: "Widget Pro. Expected 100 units."

Operator: "Received 98"
System: "Quantity short. Please confirm 98 received."

Operator: "Confirm"
System: "98 units recorded. Lot number?"

Operator: "Lot 2024-11-15"
System: "Lot recorded. Expires?"

Operator: "Expires March 2026"
System: "Expiry recorded. Put away to location A-12-03."
```

**Picking workflow**:
```
Operator: "Start picking wave 456"
System: "Starting wave 456. 47 picks. Navigate to location B-05-12."

Operator: "At B-05-12"
System: "Correct location. Pick 5 units of SKU ABC-123."

Operator: "Picked 5"
System: "Scan to verify."

Operator: [scans barcode]
System: "Verified. Place in tote 3. Next pick: location B-07-08."
```

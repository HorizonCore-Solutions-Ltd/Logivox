# Quality Reports Module

## Overview

The Quality Reports module generates comprehensive analytics and management reports with PDF export, email distribution, and executive summaries. It provides 7 pre-configured report types covering inspections, NCRs, CAPAs, supplier performance, trends, compliance, and executive summaries.

## Key Features

### Report Types

1. **DAILY**: Daily quality metrics and alerts
2. **WEEKLY**: Weekly quality summary and trends
3. **MONTHLY**: Comprehensive monthly analysis
4. **QUARTERLY**: Strategic quarterly review
5. **ANNUAL**: Year-end quality report
6. **AD_HOC**: Custom on-demand reports

### Report Categories

1. **INSPECTION_SUMMARY**: Inspection results and pass rates
2. **NCR_ANALYSIS**: Non-conformance trends and costs
3. **CAPA_EFFECTIVENESS**: CAPA performance and closure rates
4. **SUPPLIER_PERFORMANCE**: Vendor quality scorecards
5. **QUALITY_TRENDS**: Long-term quality metrics
6. **COMPLIANCE**: Regulatory compliance status
7. **EXECUTIVE_SUMMARY**: Management dashboard

### Export & Distribution

- **PDF Export**: Professional formatted reports
- **Excel Export**: Raw data for analysis (planned)
- **Email Distribution**: Automated distribution lists
- **Scheduling**: Auto-generate on schedule
- **Approval Workflow**: Draft → Review → Approved → Published

## Workflows

### Generating a Report

```
Manual Generation:
1. Navigate to /dashboard/qc/reports
2. Click desired quick-generate button OR
3. Click "Create Report" for custom report
4. Select report type and category
5. Set reporting period (start/end dates)
6. System queries database
7. Calculates metrics
8. Generates summary and findings
9. Status = DRAFT
10. Review and edit if needed
11. Submit for approval (if required)

Automated Generation:
1. Reports scheduled in system
2. Cron job runs at specified time
3. Auto-generates report
4. Emails to distribution list
5. Saves to report library
```

### Approving a Report

```
1. Report generated with Status = DRAFT
2. Quality Manager reviews
3. Edits if necessary
4. Clicks "Approve Report"
5. System prompts for approval signature
6. Status changes to APPROVED
7. Approved By and Approved Date recorded
8. Ready for publication
```

### Publishing a Report

```
1. Approved report
2. Click "Publish Report"
3. Status changes to PUBLISHED
4. Added to public report library
5. Automatically emailed to distribution list
6. Available for export
```

### Exporting to PDF

```
1. Open report detail page
2. Click "Export PDF"
3. System generates PDF:
   - Company header/footer
   - Report metadata
   - Executive summary
   - Key findings
   - Metrics (tables/charts)
   - Recommendations
   - Signatures (if approved)
4. Download begins
5. File named: REPORT-NUMBER_DATE.pdf
```

### Emailing a Report

```
1. Open report detail page
2. Click "Email Report"
3. System prompts for recipients
4. Enter email addresses (comma-separated)
5. Optional: Add message
6. Click "Send"
7. System:
   - Generates PDF attachment
   - Sends email with report
   - Records emailedAt timestamp
   - Updates recipient list
8. Confirmation message displayed
```

### Writing Effective Summaries

**Poor Example:**

> "Quality was good this month."

**Good Example:**

> "Quality performance achieved 93.2% pass rate in January, 1.8 percentage points below target due to packaging issues from Vendor ABC (18 NCRs, $34K impact). CAPA initiated to address root cause. Overdue CAPAs require immediate management attention to maintain compliance."

**Elements:**

- Specific metrics
- Comparison to targets
- Root causes identified
- Financial impact
- Actions being taken
- Items requiring attention

### Key Findings Format

Use bullet points with impact:

- ✅ **Positive**: "Supplier XYZ achieved zero defects for 6th consecutive month"
- ⚠️ **Concern**: "NCR rate increased 0.3% due to packaging issues"
- 🔴 **Critical**: "3 CAPAs overdue by 2+ weeks, compliance risk"

### Recommendations

Make them SMART:

- **S**pecific: "Conduct audit of Vendor ABC packaging process"
- **M**easurable: "Achieve <2 NCRs per month from Vendor ABC"
- **A**ssignable: "Owner: Procurement Manager"
- **R**elevant: "Addresses $34K monthly quality cost"
- **T**ime-bound: "Complete by 2/15/2026"
